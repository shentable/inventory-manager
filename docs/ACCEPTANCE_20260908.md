# 消耗看板与小数库存验收

验收版本：`1.15.1-vps-consumption-tenths`；数据库版本：`20260908_09`。

## 功能验收

- 店长、管理员可使用消耗看板；店员无入口，直接访问接口返回 403，未登录返回 401。
- 以确认后的双人盘点为基准，按期初实盘 + 实际入库 − 期末实盘 − 已确认报损反推用量，
  按有效周期总天数计算日均消耗。盘点调账不重复计入，预测不写库存流水。
- 缺少历史、延迟确认、审批期间库存变动、跨盘点报损、负用量、过期库存等情况保留核查
  原因，不给出无依据的余量和补货预测。现场不足优先提示，未注明到货日的订单单独展示。
- 个、袋、kg、公斤、L、升、米及自定义单位均支持 0.1；整数显示 `2`，小数显示 `2.3`。
  入库、采购、盘点、最低库存和报损统一支持小数，包含不足 1 单位的报损。
- 验证跨批次扣完 0.3、连续十次扣减 0.1、非法小数拒绝、整数与小数显示，以及移动端
  和中英文界面。库存预填进入报损页也完成回归。
