# 入库权限与更正验收

发布版本：`1.15.1-vps-receipt-corrections`；数据库：`20260908_10`。

- 店员可以直接入库，并查询、更正自己的直接入库；店长和管理员可处理全部记录。
- 数量、效期、备注更正保留原始记录、操作人、原因和前后值，并以差额追加库存流水。
- 覆盖 0.1 小数、部分扣减、撤销未扣减入库、越权访问、过期页面和并发更正保护。
- 后续已确认盘点覆盖的入库数量通过重新盘点核实，效期与备注仍可更正。
- 消耗看板计入更正差额，原始入库不重复计算。

`SKIP_ANDROID=1 ./scripts/verify.sh` 通过：135 项 Python 测试、10 项 Rust 测试、
49 项双后端契约检查，以及两个后端各 14 项浏览器测试。迁移、语法、许可、双语检查通过。
现有生产备份分别通过 Python/Rust 升级演练，原业务字段保持一致，十分位数量不重复换算。

发布范围为 VPS Rust 服务与随包 Web/PWA，不包含独立 Android 签名 APK。
